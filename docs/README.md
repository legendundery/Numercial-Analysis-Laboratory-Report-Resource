本仓库存放数值分析实验报告的源代码和简易发行版，以下是报告内容：

本项目以C++20为底层语言，使用PDCurses终端UI库进行交互，支持多种数值计算方法和结果可视化。

## 项目特点

- **模块化架构**：UI → Manager → Calc 三层分离，便于维护和扩展
- **终端界面**：使用PDCurses提供跨平台的交互式界面
- **多标签页输出**：支持摘要、表格、曲线等多种输出形式
- **预设系统**：内置多个典型算例，支持自定义输入
- **收敛性分析**：迭代法自动分析对角占优性和谱半径

## 技术栈

**核心语言：** C++20

**编译器：** clang++ 20.1.8 (MSYS2 MinGW64)

**UI库：** PDCurses

**架构模式：**

- **UI层** (`ui.cpp/ui.h`)：负责界面渲染和用户交互
- **Manager层** (`manager.cpp/manager.h`)：负责数据管理、预设系统、结果展示
- **Calc层** (`calc.cpp/calc.h`)：纯算法实现，无UI依赖

**构建系统：** VS Code Tasks (clang++ 直接编译)

**调试器：** gdb 16.3

## 第四章特性

### 迭代法实现

**雅可比迭代法（Jacobi）**

- 迭代矩阵：B_J = -D^(-1)(L+U)
- 并行更新策略
- 自动计算谱半径

**高斯-赛德尔迭代法（Gauss-Seidel）**

- 迭代矩阵：B_GS = -(D+L)^(-1)U
- 串行更新策略（in-place）
- 通常比雅可比收敛更快

**松弛迭代法（SOR）**

- 迭代矩阵：B_ω = (D+ωL)^(-1)[(1-ω)D - ωU]
- 最优松弛因子：ω_b = 2/(1 + √(1-ρ(B_J)²))
- 支持自动计算或手动指定松弛因子

### 收敛性分析

- **充分条件检查**：严格对角占优判定
- **充要条件检查**：谱半径 ρ(B) < 1
- **误差追踪**：记录每次迭代的 ∞-范数误差
- **自动停止**：达到精度要求或最大迭代次数

### 预设矩阵系统

内置多个预设矩阵（按收敛性排序）：

1. 严格对角占优矩阵（保证收敛）
2. 对称正定矩阵
3. 一般线性方程组
4. 支持自定义输入矩阵

### 多标签页输出

- **摘要标签**：方法信息、收敛性分析、解向量
- **迭代过程标签**：每次迭代的 x 值和误差
- **迭代矩阵标签**：显示 B_J、B_GS 或 B_ω 矩阵
- 使用左右箭头键切换标签页

## 操作说明

- **↑↓ 键**：在实验列表、输入区、输出区间切换焦点
- **←→ 键**：在输出区标签页间切换
- **回车键**：在输入区确认输入并计算
- **n 键**：在矩阵方法中切换预设矩阵
- **a 键**：添加自定义矩阵
- **m 键**：在矩阵方法中手动输入矩阵
