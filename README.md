本仓库存放数值分析实验报告的源代码和简易发行版，以下是报告内容：

本项目以C++为底层语言，使用终端为界面进行交互（注意兼容性），可以选择不同的计算方法进行计算（和误差分析等，待定）；必要时使用win原生窗口和图形API显示画面（此处本打算将项目打包到docker用python，但考虑不同系统版本兼容性，最终决定使用单一语言）

计划实现的计算方法有：

第二章 方程(组)的迭代解法
1.根的初值确定方法
1.1 画图法
1.2 对分法
1.3 扫描法

2.优化的迭代法
2.1 埃特肯法
2.2.1 牛顿迭代法
2.2.2 牛顿下山法
2.3.1 单点弦截法
2.3.2 双点弦截法

第三章 解线性方程组的直接法
1.1 高斯消元法
1.2 克劳特消元法
2.平方根法
3.（追赶法）
4.1 列主元素法
4.2 全主元素法

第四章 解线性方程组的迭代法
1.雅可比迭代法
2.高斯-赛德尔迭代法
3.松弛迭代法

第五章 插值法
1.差商、差分
2.不等距节点下的牛顿基本差商公式
3.等距节点下的牛顿基本差商公式
4.牛顿前插公式
5.牛顿后插公式
6.拉格朗日插值公式
7.反插值
8.埃尔米特插值公式

第六章 数值积分
1.牛顿-科特斯求积公式
2.复化求积公式
3.复合梯形公式
4.复合辛普森公式
5.龙贝格法
6.高斯求积公式

由于时间原因暂不实现自定义表达式求值，输入均以简单多项式为例；后期可考虑集成表达式求值库以实现更复杂的输入需求。

实现工具链：
C++20
编译器：clang++ 20.1.8
构建工具：cmake
调试器：gdb 16.3
